# FUTURE_DS_03
This project is a Marketing Funnel & Conversion Performance Dashboard developed using Python Flask, Pandas, Matplotlib, Seaborn, HTML, and CSS.
The system analyzes marketing channel performance such as Facebook Ads, Instagram Ads, Google Ads, Email Marketing, and Organic Search. It calculates important marketing metrics including lead conversion rate, qualified lead percentage, overall conversion rate, cost per lead, and customer acquisition cost.
The Python backend processes the marketing dataset, performs funnel analysis, identifies customer drop-offs, and generates charts automatically. The charts include funnel performance, conversion rates, customer acquisition comparison, and customer acquisition cost analysis.
The HTML frontend displays KPI cards, charts, marketing insights, recommendations, and detailed marketing data in a dashboard format. The dashboard helps businesses understand which marketing channel performs best and where improvements are needed in the conversion funnel.
This project is useful for marketing analytics, business intelligence, campaign optimization, and conversion tracking in digital marketing.
